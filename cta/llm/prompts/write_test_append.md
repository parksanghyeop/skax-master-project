아래 작업 지침서에 따라, [수집된 정보]에 있는 기존 테스트 파일에 **추가할 새 테스트 메서드만** 작성하라.

[작업 지침서]
$instruction

[수집된 정보]
$context

[프로젝트 관례]
$style

[직전 시도에 추가했던 코드 — 처음이면 비어 있음]
$current_code

[직전 실행 실패 내용 — 처음이면 비어 있음]
$last_failure

출력 규칙: 코드 블록(``` ... ```) 하나로, 새로 필요한 import 문(있을 때만)과 새 테스트 메서드
(필요하면 새 헬퍼 메서드·필드)만 출력한다. package 문, 클래스 선언, 기존 메서드는 출력하지 않는다.
기존 파일에 이미 있는 필드·헬퍼·import는 다시 선언하지 말고 그대로 쓴다. 설명 문장을 붙이지 않는다.
