# E2E 서비스 개발 단계 (3단계) — 개요·현황·마일스톤

작성일 2026-09-06. PoC(1단계)·테스트 및 고도화(2단계)를 마치고 3단계로 넘어가는 시점의 기준 문서다.
3단계 스킬(`.claude/skills/phase3-e2e/SKILL.md`)의 목표를 그대로 따른다.

> **3단계 목표**: 개발자(나 아닌 사람)가 설치 가이드만 보고 자기 프로젝트에 돌릴 수 있는 상태.
> 데모 시나리오 2개가 처음부터 끝까지 매끄럽게 도는 것.

**진행 상태 (2026-09-06)**: M8-a 6건 완료 · M8-b B-1(스킬)·B-2(결함 세트 v2)·B-4(MCP)·B-5(메모 불변식) 구현 완료,
B-3과 전/후 측정은 Docker·게이트웨이 환경 대기 · M8-c C-2(README)·C-4(문서 정합)·C-5(한계 절)·길이 조정 완료,
C-1(데모 3회)·C-3(설치 테스트)·C-7(Linux)은 환경·사람 필요. 세부는 [`e2e-notes.md`](e2e-notes.md), [`릴리스체크리스트.md`](릴리스체크리스트.md).

3단계는 **넓히는 단계가 아니라 닫는 단계**다. 새 아이디어는 "향후 과제"로 보낸다.
예외는 하나, 사람 멘토 피드백인 **워크플로우에 스킬 붙이기**다. 기술 어필이 부족하다는 지적이라 3단계 안에서 수치와 함께 닫는다.

## 3. 마일스톤

세 묶음으로 나눈다. 각 묶음은 관문을 통과해야 다음으로 간다(사용자 승인).

### M8-a 마감 — 남이 돌릴 수 있게 (1주)

코드 변경이 작고 신뢰를 올리는 것부터. CI, 설정 파일, 시크릿 테스트, 종료 코드 문서, 에러 메시지 다음 행동.
관문: CI에서 `ruff` + `pytest -q`(재생 모드) 그린. `cta.toml` 한 파일로 게이트·재시도·시간 초과·모델을 바꿀 수 있다. 시크릿 3 테스트 초록.

### M8-b 확장 — 기술 어필 (1.5주)

MCP 서버(core 재사용), 워크플로우 스킬(ADR-0016 → 스킬 2개 → 전/후 수치), 판단 메모 검색 강화 + 불변식 테스트, 결함 세트 확장.
관문: Claude Code에서 MCP로 `generate`가 돈다. 스킬 전/후 표가 하네스 수치로 나온다. 결함 세트 12건 이상에서 검출률 재측정.

### M8-c 릴리스 — 닫기 (1주)

데모 2개 3회 연속 성공, README 재작성, 문서 정합(ADR·architecture·contracts), 산출물 문서, 알려진 한계.
관문: 릴리스체크리스트 전부 체크. 데모 녹화.

## 4. 3단계 완료 조건 (최종 관문)

1. **설치 테스트**: 리포를 모르는 사람이 `docs/사용가이드.md`만 보고 새 Maven 프로젝트에 `cta generate`를 성공시킨다. 걸린 시간과 막힌 지점을 기록한다.
2. **데모 2개**가 문서화된 명령 순서로 3회 연속 성공한다(콜드 스타트 / 유지보수 + escalate → resolve).
3. **CI 그린**: ruff, pytest 재생 모드, 층 분리, 게이트 불변식. Docker·Neo4j 통합은 별도 잡(수동 또는 야간).
4. **MCP**로 최소 `generate`·`maintain` 호출이 되고, CLI와 로직 중복이 없다(둘 다 core 호출 껍데기).
5. **스킬 전/후 수치**가 하네스 결과 파일과 함께 산출물에 있다.
6. **시크릿 3 테스트** 초록, 커밋 diff에 키 모양 문자열 없음.
7. **문서 정합**: ADR 목록 = 구현, `contracts.md` = `PoC구현.md` §2.0, `architecture.md` 모듈 표에 새 모듈(mcp, skills, config) 한 줄씩.
8. **알려진 한계**가 사용가이드와 산출물 양쪽에 같은 내용으로 있다.

## 5. 하지 않을 것 (향후 과제로)

| 항목 | 이유 |
|---|---|
| 멀티모듈 Maven, Gradle | 프로젝트 형태 확장은 닫는 단계의 일이 아니다 |
| CALLS 엣지, 메서드 단위 COVERS | 그래프 확장. 현재 질의 3종으로 시나리오가 돈다 |
| AST 전용 파서 전환 | 정규식 파서 한계는 문서화로 닫는다 |
| Defects4J·EvoSuite | 리눅스 환경 확보 시(ADR-0014). 하네스의 케이스 교체 지점은 유지 |
| 모델이 스스로 스킬을 고르는 도구 | R4(도구 6개) 위반, 재생 깨짐. 규칙 기반 선택으로 간다 |
| 자율 반복 실행(ralph-loop류) | CLAUDE.md 원칙과 충돌 |
