# ADR-0012: 테스트 작성 루프 = LangGraph 서브그래프 + interrupt (소급 기록)

- 상태: 승인 — v4 설계에서 확정된 결정의 ADR 소급 기록 (2단계 시작 의식)
- 관련: v4 2.2·2.3, phase2 스킬. 구설계(직접 while 루프)를 대체
- 번호 주석: phase2 스킬은 이 결정을 "ADR-0010"으로 예정했으나, 0010·0011을
  LLM 백엔드 결정이 먼저 사용했다. 이후 스킬 문서의 ADR-0010 언급은 이 문서를 가리킨다

## 결정

1. 테스트 작성 에이전트의 반복(생성→실행→분기)은 직접 while 루프가 아니라
   **LangGraph 서브그래프**로 구성한다. 이유: 멈췄다 이어 하기(checkpoint)가
   내장돼 있어, 단계 사이의 "사람에게 넘기기"와 반복 도중의 사용자 개입을
   같은 장치로 처리할 수 있다.
2. 반복 중 판단이 필요한 실패·한도 도달 시 **LangGraph interrupt**로 정지하고,
   사용자의 답(계속/중지/힌트)으로 재개한다. 1단계에서는 골격(UserGate 포트 +
   자동 '계속' 스텁)까지 구현했고, 실연결은 2단계 M6에서 한다.
3. 반복 횟수·비용 상한은 그래프 상태의 숫자로 관리하며, 사용자 허락 없이
   초과하지 않는다 (현재: 3회마다 질문, 하드 캡 6회).

## 현재 구현 상태

`core/writer_graph.py`가 1을 구현했고(1단계 M3), 2의 실연결이 2단계 과제다.
