문제·원인, 리서치 출처, 해결, 전후 변화) / 검증 캡처(입력, 도구 호출 순서, 최종 결과) /

- 기존 내용은 덮지 말고 병합하고, 해결된 문제는 해결 과정을 추가한다
- 요청 시 이 파일에서 회사 제출 양식(핵심 구현 내용/문제 해결·리서치 표/핵심 동작 검증)
