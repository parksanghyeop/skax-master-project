방금 작업에 대해 DoD를 검증하라. 주장하지 말고 실행하라.

1. `ruff check . && ruff format --check .` 실행, 결과 첨부
2. `pytest -q` 실행 (test_layering.py 포함 여부 확인), 결과 첨부
3. 새 동작의 테스트가 어느 파일에 있는지 명시 (Fake 어댑터/카세트 중 무엇 기반인지)
4. 새·변경 공개 함수의 타입 힌트 유무 확인
5. 실제 실행 증거 (명령과 출력 일부)
6. `docs/contracts.md`·v4 설계와 어긋난 점 유무
7. 새·변경 파일의 주석 규칙 충족 — 파일 머리, 공개 함수 docstring, 매직값 주석.
   2년차가 처음 읽어도 따라올 수 있는지 자문하라
8. 문서 병행 표 기준으로 같이 갱신해야 할 문서가 이번 커밋에 포함됐는지

하나라도 실패면 "미완"으로 보고하고 고칠 것을 제안하라. 마지막에 CLAUDE.md의
보고 형식(변경/검증/미완/다음) 4줄로 요약하라.
